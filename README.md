# 🚌 Bus Booking & Management Dashboard

A lightweight and powerful bus booking and management system built with pure HTML.  
Designed to manage buses, seat capacity, schedules, ticketing, and reporting with ease.

---

## 🚀 Live Demo

https://ferasalsouri.github.io/bus-booking/

---

## ✨ Features

- 🔄 Full CRUD operations (Create, Read, Update, Delete)
- 🪑 Manage seat capacity per bus
- 📅 Track seats based on date and time
- 🎫 Generate tickets for each passenger
- 📊 Detailed reports for each bus
- 📤 Export data to Excel
- 📥 Import Excel data for management
- 📄 Generate and export PDF reports and tickets
